# Synthetic Data Notice

> [!CAUTION]
> **COMPLETELY SYNTHETIC RESEARCH DATASET**
> **Research prototype, not clinically validated, not for real diagnosis.**

All data files located in this directory (`data/synthetic/`) are generated entirely synthetically via probabilistic simulation and statistical rules.

1. **Zero Real Patient Data**: None of the patient names, demographics, symptoms, lab investigations, adherence logs, contacts, or clinical records correspond to real individuals or protected health information (PHI).
2. **Geographic Grounding**: Village names and districts (Maharashtra, India) are used strictly as spatial proxies to realistically simulate rural public health surveillance and frontline ASHA worker workflows.
3. **Clinical Calibration**: Symptom profiles and lab sensitivities are calibrated against published epidemiological literature and NTEP (National TB Elimination Programme) guidelines for benchmarking research and workflow prototyping only.
4. **Intended Use**: This data is intended exclusively for software development, agent workflow testing, model training prototypes, and user interface demonstration. It must NEVER be used for clinical decision-making or medical diagnosis.
